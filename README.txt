SOUND WAVE FESTIVAL 2027 - 수업 과제용 웹사이트

실행 방법
1. 압축을 푼 뒤 sound_wave_festival 폴더를 엽니다.
2. index.html 파일을 Chrome 또는 Edge에서 실행합니다.
3. 상단 사전등록 버튼을 누르면 register.html 신청 페이지로 이동합니다.
4. 전체 일정 보기 / 전체 프로그램 보기 버튼은 팝업으로 열립니다.

파일 구조
- index.html : 메인 행사 안내 페이지
- register.html : 사전등록 신청 페이지
- css/style.css : 전체 디자인 및 반응형 스타일
- js/main.js : 메뉴 및 일정/프로그램 팝업 기능
- js/register.js : 사전등록 폼 검증 및 완료 화면
- assets/sound-wave-hero.png : 웹페이지에 삽입된 실제 메인 이미지
- assets/reference-poster.png : 사용자가 제공한 디자인 참고 이미지

참고
- 행사 날짜, 아티스트, 장소, 티켓 가격은 과제용 가상 정보입니다.
- 사전등록은 브라우저에서 완료 화면만 보여주는 데모이며 실제 결제/서버 저장은 하지 않습니다.
- 웹폰트는 Google Fonts를 사용하므로 인터넷 연결 시 지정 폰트가 표시됩니다.
